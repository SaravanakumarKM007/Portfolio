SARAVANAKUMAR - UI/UX + DIGITAL MARKETING PORTFOLIO
(Light / Dark mode, hover effects and animations included)

1. Unzip and double-click index.html to open it in your browser.
2. Photo: save your photo as images/photo.png (transparent PNG looks best).
3. Email: change "yourname@gmail.com" in index.html AND script.js.
4. Social links: edit the Instagram / LinkedIn / Behance links in the Contact section.
5. Projects: in index.html each project is an <article class="card"> block.
   Change the title, description and category (data-c = ux, mkt or brand).
   To use a real image instead of the gradient poster, replace the
   <div class="poster ..."> block with: <img src="images/project1.jpg" alt="" style="height:240px;width:100%;object-fit:cover;border-radius:12px">
6. CV button: put your CV in this folder, then change href="#" download to href="cv.pdf" download
7. Colours: edit the variables at the top of style.css (:root and [data-theme="dark"]).
8. To go live for free: upload the folder to Netlify Drop, GitHub Pages or Vercel.
